# 🌙 Shutdown Ritual

> [!NOTE]
> Inspired by **Cal Newport's [*Deep Work: Rules for Focused Success in a Distracted World*](https://calnewport.com/the-book-facebook-doesnt-want-you-to-read/) (2016)** and its [shutdown ritual](https://calnewport.com/drastically-reduce-stress-with-a-work-shutdown-ritual/): capture loose ends, plan the next steps, and let the evening be yours.

A Codex skill for closing your workday and reclaiming the evening.

## How it works

**✨ Done today → 🧺 Loose ends → 🌱 Tomorrow → 🌙 Tonight**

Review suggestions from today's chats with checkboxes, then plan one question at a time. Finish with clear tables of tasks, time ranges, buffer, and free time. Rest counts.

## Install

```sh
git clone https://github.com/Feng-Jay/Shutdown-Ritual.git "${CODEX_HOME:-$HOME/.codex}/skills/shutdown-ritual"
```

## Use

```text
Use $shutdown-ritual to help me close my workday.
```
